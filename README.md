# ammalabbasi.github.io

Personal site of Ammal Abbasi, PhD. A single static `index.html` with no build step, served by GitHub Pages at
https://ammalabbasi.github.io.

- News: `<li class="news-item">` entries in the News column.
- Featured publications: `<article class="pub-card">` blocks; images in `assets/pubs/` (each paper's key figure).
- Other publications: the `<ul class="more">` list under the cards.
- Photo: `assets/photo.jpg` (X profile photo).
