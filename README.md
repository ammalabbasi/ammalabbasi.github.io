# ammalabbasi.github.io

Personal site of Ammal Abbasi, PhD. It is plain HTML/CSS/JS with no build step, served by GitHub Pages at
https://ammalabbasi.github.io.

- Publications live in the `PUBS` / `PREPRINTS` arrays at the bottom of `index.html`. Add an entry, set
  `sel: true` to feature it as a card, and use `tags` to control the filter buttons.
- News items are the `<li>` entries in the `News` aside.
- To show a photo, drop a square image at `assets/photo.jpg`; it replaces the "AA" monogram automatically.
- Publication thumbnails are decorative 96-channel SBS spectra seeded from each title. They are not data.
